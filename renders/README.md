# Vizuálne rendery krabičky AirGap Paste

V tomto adresári nájdete všetky doteraz vygenerované vizuálne koncepty, komerčné Kickstarter rendery, EDC prenosné verzie a CAD náhľady krabičky AirGap Paste.

Tieto 4 koncepty kombinujú overené komerčné predajné trendy z úspešných hardvérových crowdfundingových kampaní s dokonalým **Design for Additive Manufacturing (DFAM)** pre tlačiareň **Bambu Lab A1**:

| Súbor | Koncept | Obchodný / Kickstarter ťahák | Prečo sa perfektne tlačí na Bambu Lab A1 |
| :--- | :--- | :--- | :--- |

| `23_kickstarter_retro_cassette.jpg` | **The Retro Cyber Cassette** (C-60) | • **Nostalgia retro-computingu:** Dizajn inšpirovaný 80s mikro-kazetami a disketami s etiketou `AIRGAP C-60 SECURE TOKEN`.<br>• IT a mechanical keyboard komunita na Reddite a Kickstarteri tento retro-tech štýl doslova zbožňuje (obrovská viralita). | • **Plochý boxy profil:** Nulové deformácie pri tlači, blesková tlač.<br>• Vynikajúca možnosť pre viacfarebnú tlač (Bambu AMS) retro etikety v horných vrstvách. |
